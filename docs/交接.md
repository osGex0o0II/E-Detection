## 维护约束

- `NativeCore` 不引用 WinUI；`Domain`、`Desktop.Core` 保持 UI-free。
- 行级规则统一由 `DetectionRowRulePipeline` 执行，顺序为电压 → 电流 → 有功 → 功率因数 → 温度；冻结检测随后运行。
- 规则或报告格式变更前，核对 [数据模型](data-model.md) 并补测试。
- 用户密钥存于 Windows Credential Locker，不写入 `settings.json`。
- 报告先写临时文件，校验后移动到目标名；安装与卸载脚本需保留路径安全检查。

## 注意事项

- `SettingsView`、`MainViewModel` 与 `NativeDetectionBackendService` 已拆为 partial 文件；静态测试扫描 `*.cs` 文件组。
- xUnit v3 使用 `Microsoft.Testing.Platform`；保留 `global.json` 的测试运行器配置。
- PowerShell 脚本用 `pwsh` 7；Windows PowerShell 5.1 缺少部分 API。
- 发布物可能未签名，状态以 Release 说明为准；SHA-256 仅校验完整性，不验证发布者身份。
- 修改发布流程后运行包健康、便携安装与 Inno Setup 安装器烟测；UI 烟测需桌面会话。

项目限制见 [项目状态](状态.md)。
