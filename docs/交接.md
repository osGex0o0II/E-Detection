开发命令见 [桌面开发指南](../desktop/README.md)，模块依赖见 [架构文档](architecture.md)，检测字段与规则见 [数据模型](data-model.md)。

## 维护约束

- `NativeCore` 不引用 WinUI；`Domain` 和 `Desktop.Core` 保持 UI-free。
- 行级规则统一通过 `DetectionRowRulePipeline`，顺序为电压 → 电流 → 有功功率 → 功率因数 → 温度；冻结检测在其后执行。
- 规则或报告格式变化前，检查 [数据模型](data-model.md) 并补充对应测试。
- 用户密钥存于 Windows Credential Locker，不写入 `settings.json`。
- 报告先写临时文件并校验，再移动到目标文件名；安装、卸载脚本需保持路径安全检查。

## 注意事项

- `SettingsView`、`MainViewModel` 和 `NativeDetectionBackendService` 已拆为多个 partial 文件。修改静态测试时需扫描相应 `*.cs` 文件组。
- xUnit v3 使用 `Microsoft.Testing.Platform`；保留 `global.json` 中的测试运行器配置。
- PowerShell 脚本使用 `pwsh` 7；Windows PowerShell 5.1 不支持部分 API。
- WinUI 自包含发布需要同时设置 `WindowsAppSDKSelfContained=true` 和 `WindowsPackageType=None`。
- 发布物可能未签名，具体状态以 Release 说明为准。SHA-256 仅验证文件完整性，不能验证发布者身份。
- 修改发布流程后运行包健康、便携安装和 Inno Setup 安装器烟测；交互式 UI 烟测需单独提供桌面会话。

项目限制见 [项目状态](状态.md)，变更记录以 Git 历史为准。
