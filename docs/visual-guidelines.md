## 标志

**唯一基础图形：数据波形 + 一个红色检测点。** 不使用盾牌、锁、齿轮、闪电、额外光点、立体光效或多色渐变。波形承接早期 E-Detection 图标的辨识度；红点作为识别性的品牌点缀，不代表每次检测都出现异常。

- README 主资源：[单色 SVG](images/e-detection-logo.svg)。
- Windows 应用图标：`desktop/EDetection.Desktop/Assets/Icons/app.ico`；运行态图标：同目录 `running.ico`。
- 标题栏以等价的 XAML 矢量路径呈现，保证在深色主题下仍具对比度。
- 标志缩小后应能辨认单条波形与红点，禁止在徽标内加入文字或小型附属符号。

## 颜色

| 用途 | 色值 | 约定 |
| --- | --- | --- |
| 主标记 | `#242427` | 近黑色，波形与浅色背景形成稳定对比 |
| 标志背景 | `#F8F8F8` | 无渐变的浅中性色 |
| 标志外边缘 | `#E4E4E7` | 低对比度细边界，让浅色图标在白色页面上可见 |
| 红色检测点 | `#D13438` | 仅在标志中保留一个饱和红色圆点 |
| UI 主要操作 | Windows 系统 Accent | 保留 WinUI 原生按钮与选中态语义，勿将所有操作染成红色 |
| 状态与等级 | 使用既有成功 / 警告 / 错误语义 | 红色不应替代具体告警标签或文案 |

轻量、克制、高可读是原则。避免蓝绿色科技渐变、通用安全盾牌，以及无意义的荧光装饰。

## 文档与截图

1. README 首屏只包含 Logo、产品定位、下载入口和主要平台信息；详细文件索引留在技术文档。
2. 真实截图必须来自运行中的软件；标注空闲、处理中或完成状态，不能用后期填充的统计数据伪装完成结果。
3. 当能够使用 Windows 测试环境和可公开的匿名 CSV 样本时，补充一张 **非零检测结果** 的真实截图，展示异常明细与报告；不要披露真实场所、设备编号或敏感路径。
4. 优先使用系统字体、Fluent 组件、中性色、清晰的表格与较紧凑的设置行；不要为了“科技感”额外添加装饰卡片。
5. 更新 Windows 图标时，同时核对 `app.ico`、`running.ico`、标题栏与文档 Logo，确保一致。
