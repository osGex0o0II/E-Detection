## 更新约定

- 产品功能变化：同步更新主 README 的简明能力描述；详细实现只记录在架构或数据模型。
- 测试和发布结果：记录到[当前状态](状态.md)，写明提交、日期与运行环境；不要把临时 CI 计数反复复制进主 README。
- 文件路径、参数和命令变化：优先修改[桌面开发指南](../desktop/README.md)。
- 真实软件截图：来自实际 Windows 应用，标记运行或空闲状态；不能把合成图或填充的模拟结果称为真实检测记录。
- 许可证：只有维护者明确决定授权条款后才能增加 `LICENSE`，不得用示例文本代替法律声明。
